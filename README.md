## Projects

### [drive-data-stripper](./drive-data-stripper)
- **Description:** A guided Python CLI (plus a local web UI) that strips proprietary data and file metadata from a document before it's shared with a frontier model, with a reversible "scaffold" mode that swaps sensitive values for placeholder tokens and restores them afterward. Handles Office docs (.docx/.xlsx/.pptx), Power BI packages (.pbix/.pbit/.pbids), PDFs, images (including OCR-based redaction of text in pixels), and plain-text/JSON formats (including .bim). Also includes an interactive review mode, an append-only audit log, batch/folder processing, and key-file based sharing for teams. Includes a companion browser-extension proof of concept (`drive-data-stripper/browser-extension`) that intercepts sensitive text before it's sent to an AI chat.
- **Technologies:** Python, Click, Flask, Pillow, pytesseract, pypdf, python-docx, python-pptx, openpyxl, cryptography, JavaScript (MV3 extension)
